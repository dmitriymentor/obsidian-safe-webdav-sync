# Safe WebDAV Sync 0.2.8

- Слишком длинное имя ещё не загруженной Markdown-заметки сокращается автоматически при синхронизации.
- Полное исходное название сначала сохраняется заголовком внутри заметки, после свойств. Существующий текст не обрезается, YAML-даты не переписываются. Повторный запуск не дублирует заголовок.
- Короткое имя сохраняет расширение и получает стабильный суффикс. Занятые локальные пути не перезаписываются; соответствующая версия с другого устройства обрабатывается обычной синхронизацией.
- Перед изменением создаётся проверенная зашифрованная локальная копия. История имён доступна в последнем отчёте.
- Используется переименование средствами Obsidian; ссылки обновляются согласно настройке автоматического обновления ссылок.
- Проверка плана ничего не переименовывает. Длинные имена папок, вложений и пути с историей удаления требуют ручной обработки.

Обновите плагин через BRAT, перезапустите Obsidian и выполните ручную синхронизацию. Сокращать название проблемной заметки вручную больше не нужно.
